# 🤖 AI-Powered Sentiment Analysis System

## 📌 Project Overview

The AI-Powered Sentiment Analysis System is a Machine Learning based application that analyzes text and predicts its sentiment as:

- 😊 Positive
- 😞 Negative
- 😐 Neutral

## 🛠️ Technologies Used

- Python
- Machine Learning
- Streamlit
- Pandas
- Naive Bayes Algorithm
